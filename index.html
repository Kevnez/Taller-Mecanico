Requerimientos del Sistema (RF1 - RF8)

  • RF1: El sistema debe mostrar un menú con opciones interactivas[cite: 1].
  • RF2: El sistema debe permitir registrar un auto nuevo con patente, marca, modelo, dueño, problema y estado[cite: 1].
  • RF3: El sistema no debe permitir registrar dos autos con la misma patente (Control de claves únicas)[cite: 1].
  • RF4: El sistema debe permitir buscar un auto por su patente de forma directa[cite: 1].
  • RF5: El sistema debe permitir mostrar todos los autos registrados[cite: 1].
  • RF6: El sistema debe permitir cambiar el estado de un auto (Ejemplos: En espera, En reparación, Listo)[cite: 1].
  • RF7: El sistema debe permitir mostrar los datos detallados de un auto[cite: 1].
  • RF8: El sistema debe permitir salir del programa de forma segura[cite: 1].

Arquitectura y Clases (Java)

1. Clase Auto

Representa los vehículos ingresados[cite: 3]. Contiene los atributos privados (patente, marca, modelo, dueño, problema, estado) y los métodos descriptivos como getPatente(), getMarca(), setEstado() y mostrarDatos()[cite: 3].

2. Clase Main

Contiene la lógica de ejecución principal[cite: 3]. Implementa el ciclo do-while junto a un switch/case, estructurando la gestión mediante un HashMap para búsquedas rápidas y un TreeMap para reportes ordenados por patente[cite: 3, 4].
